title: 'Boosting Virtual Agent Learning and Reasoning: A Step-Wise, Multi-Dimensional,
  and Generalist Reward Model with Benchmark'

abstract: 'The development of Generalist Virtual Agents (GVAs) has shown significant
  promise in autonomous task execution. However, current training paradigms face critical
  limitations, including reliance on outcome supervision and labor-intensive human
  annotations. To address these challenges, we propose <b>Similar</b>, a <b>s</b>tep-w<b>i</b>se
  <b>m</b>ult<b>i</b>-dimensiona<b>l</b> gener<b>a</b>list <b>r</b>eward model, which
  offers fine-grained signals for agent training and can choose better actions for
  inference-time scaling. Specifically, we begin by systematically defining five dimensions
  for evaluating agent actions. Building on this framework, we design an MCTS-P algorithm
  to automatically collect and annotate step-wise, five-dimensional agent execution
  data. Using this data, we train <b>Similar</b> with our crafted Triple-M strategy.
  Furthermore, we introduce the first benchmark in the virtual agent domain for step-wise,
  multi-dimensional reward model training and evaluation, named <b><em>SRM</em></b>.
  This benchmark consists of two components: <b><em>SRMTrain</em></b>, which serves
  as the training set for <b>Similar</b>, and <b><em>SRMEval</em></b>, a manually
  selected test set for evaluating the reward model. Experimental results demonstrate
  that <b>Similar</b>, through its step-wise, multi-dimensional assessment and synergistic
  gain, provides GVAs with effective intermediate signals during both training and
  inference-time scaling. The code is available at https://github.com/antgroup/Similar.'
